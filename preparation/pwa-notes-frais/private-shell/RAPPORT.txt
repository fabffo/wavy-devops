Mécanisme proposé pour les tests autorisés (non exécuté)
Le répertoire control doit être réservé à l'opérateur ; il est monté comme
répertoire, jamais comme fichier open isolé. Nginx vérifie l'existence de
/run/wavy-private-pwa/open à chaque requête, open_file_cache explicitement off.
Absence => 404 PWA et API /api/pwa ; écritures Notes de frais => 403.
La création explicite du marqueur par l'opérateur autorisé ouvre le test.
La suppression du marqueur ferme immédiatement les NOUVELLES requêtes,
sans reload Nginx, changement d'image, Docker exec, arrêt PWA ou rollback.
Une interruption après échec de rollback doit laisser le marqueur absent.
Aucun marqueur n'a été créé dans le candidat livré.
Ne pas combiner cette variante avec les overlays d'activation/edge publics.
L'endpoint pwa-integration.json du Shell conserve sa version désactivée :
l'accès de test est direct /pwa/, sans activation du menu global ERP.
